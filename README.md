# USDT Trading Portal - Mohammad

A modern, mobile-first USDT trading dashboard designed specifically for Mohammad's trading activities.

## Features

### 🎯 Core Functionality
- **Buy/Sell Transaction Tracking**: Record and manage all USDT trading transactions
- **Real-time Profit/Loss Calculation**: Automatic calculation of profits with 0.2% trading fees
- **Multiple Payment Methods**: Support for Cliq, Orange Money, Zain Cash, Bank transfers, and more
- **Local Storage**: All data persists locally on your device

### 📱 Mobile-First Design
- **Responsive Layout**: Optimized for mobile devices with touch-friendly interface
- **Modern UI/UX**: Clean, professional design with dark theme
- **Touch-Friendly**: All buttons and inputs are optimized for mobile interaction
- **Fast Loading**: Lightweight and optimized for mobile networks

### 📊 Advanced Analytics
- **KPI Dashboard**: Key performance indicators with visual cards
- **Interactive Charts**: Daily, weekly, and cumulative profit tracking
- **Payment Method Analytics**: Visual breakdown of payment method usage
- **Filtering & Search**: Advanced filtering by date range and search terms

### 💾 Data Management
- **Local Storage**: All data stored locally in your browser
- **CSV Export**: Export all trading data for external analysis
- **Data Persistence**: Data survives browser restarts and device changes
- **Backup Ready**: Easy to backup and restore data

## Getting Started

### Local Development
1. Simply open `index.html` in your web browser
2. No server or build process required
3. All data is stored locally in your browser

### Netlify Deployment
1. Connect your GitHub repository to Netlify
2. The `netlify.toml` configuration file is already included
3. Deploy with zero configuration required

## Usage

### Adding Transactions
1. Navigate to "Buy Log" or "Sell Log" tabs
2. Fill in the transaction details:
   - Date
   - Payment method
   - Amount in USDT
   - Price per USDT
   - Transfer costs (if any)
3. Click "Add Transaction" to save

### Viewing Analytics
1. Use the "Dashboard" tab to view:
   - Total profit/loss
   - Transaction counts
   - Daily averages
   - Payment method usage
   - Interactive charts

### Filtering Data
- Use the search bar to find specific transactions
- Filter by time period (7 days, 30 days, 90 days, or all time)
- All filters work across all views

### Exporting Data
- Click the export button (📥) in the header
- Download CSV file with all your trading data
- Perfect for tax reporting or external analysis
